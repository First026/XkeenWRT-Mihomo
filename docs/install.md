# Установка XkeenWRT

Актуальная пара r21 собирается только для OpenWrt 25.12.6 ARM64 APK (`aarch64_cortex-a53`). Порядок установки, точные хеши и границы нативной приёмки приведены в `INSTALL.md` и отчёте внутри соответствующего release-комплекта. Этот документ описывает контракты сборки и режимов; лабораторная проверка не разрешает изменять рабочие роутеры без поручения владельца.

Сборщик `scripts/package-build.sh` требует явно заданные пути и SHA-256 статических backend, validator и recovery, архивы замороженного снимка исходников и build-рецепта, `build_id`, архитектуру, версию, каталог результата, закреплённую лицензию Mihomo и host `apk mkpkg`. `scripts/package-build-id.sh` до компиляции backend вычисляет идентификатор из архива снимка и зафиксированного build-рецепта/toolchain, версии, архитектуры, core, helpers, init scripts и package hook; тот же идентификатор встраивается в backend. Сборщик перепроверяет идентификатор по собственным копиям входов и формирует одинаковые manifests в обоих пакетах. Он проверяет ELF и хеш закреплённого архива Mihomo, по умолчанию формирует unsigned APK и не создаёт activation markers. `XK_SIGN_KEY` передаёт ключ в `apk mkpkg`; необходимы отдельно проверенные release inputs и доверенная подпись. Штатный upstream self-updater не используется.

Для интерактивной активации, обновления и удаления на устройстве сначала должны быть завершены независимая persistent rescue, согласованность версий после ENOSPC, pending recovery и целевые ARM64 проверки. Обычный вызов `apk del` при ошибке pre-deinstall не блокирует удаление; до закрытия этих условий нельзя считать сетевой rollback гарантированным.
