# XkeenWRT 0.1.26.3

XkeenWRT — независимый порт веб-панели [XKeen-UI](https://github.com/zxc-rv/XKeen-UI) от zxc-rv для OpenWrt с движком Mihomo. За основу взят [XKeen-UI v1.4.6](https://github.com/zxc-rv/XKeen-UI/tree/b8ed60c098594c356c0ae871f77fc6598e0a9c8c). В обоих APK сохранены оригинальный текст MIT и `Copyright (c) 2026 zxc-rv`.

## Что нового

- **Запуск шлюза через Tailscale.** Вне дома панель открывается по адресу роутера в tailnet (`http://<Tailscale-IP>:1000/`). Оттуда работают ▶ «Запустить», «Перезапустить» шлюз, «Применить» на работающем шлюзе и «Остановить» — как в оригинальном XKeen-UI на Keenetic.
- **Роутер сам проверяет запуск через Tailscale.** Вы не в домашней сети, поэтому перед подтверждением роутер проверяет шлюзовый DNS и выход в интернет хотя бы через один прокси, включая узлы из подписок. Если проверка не прошла, перехват сразу снимается, домашняя сеть работает напрямую, а в панели видна причина: `NETWORK_REMOTE_DNS` или `NETWORK_REMOTE_EGRESS`. Итог проверки показан в статусе шлюза.
- **Из домашней сети всё как в 0.1.26.2.** HTTP/SOCKS, выбор отдельного клиента и блокирующая политика при сбое по-прежнему включаются только из LAN. «Применить» на работающем шлюзе работает и из LAN, и через Tailscale.
- **Безопасность.** Декодер zstd обновлён до `ruzstd` 0.9.1 ([RUSTSEC-2026-0344](https://rustsec.org/advisories/RUSTSEC-2026-0344.html)): подменённый файл правил `.mrs` мог исчерпать память роутера. В инструментах сборки панели уязвимый `picomatch` ([GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), исправленной версии нет) заменён своей исправленной копией; на роутер он не попадает, панель собрана байт в байт той же.

## Обновление

[Быстрый старт одной командой по SSH](https://github.com/First026/XkeenWRT-Mihomo#быстрый-старт) — чистая установка или обновление с 0.1.26.2. Перед обновлением нажмите в панели **Остановить**.

Если после запуска через Tailscale понадобится вернуться на 0.1.26.2, сделайте это [по инструкции](https://github.com/First026/XkeenWRT-Mihomo/blob/v0.1.26.3/docs/clean-reinstall.md#откат-01263--01262): 0.1.26.2 не прочитает журнал Tailscale-запуска. Пакеты 0.1-r26 и более ранних выпусков больше не публикуются.

## Проверка

Проверено в одноразовой ARM64 VM OpenWrt 25.12.6 (`armsr/armv8`, QEMU), не на устройстве: обновление с 0.1.26.2 установщиком `.run`; вся домашняя сеть по правилам профиля — сайт из правила через прокси, остальное напрямую; ▶ через Tailscale с проверкой DNS и выхода; отказ и возврат Direct при недоступном прокси и при недоступном DNS; «Применить» и «Перезапустить» через Tailscale; отказ HTTP/SOCKS через Tailscale; ▶, «Применить» и «Перезапустить» из LAN.
