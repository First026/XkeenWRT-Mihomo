# XkeenWRT 0.1.26.2

XkeenWRT — независимый порт веб-панели [XKeen-UI](https://github.com/zxc-rv/XKeen-UI) от zxc-rv для OpenWrt с движком Mihomo. За основу взят [XKeen-UI v1.4.6](https://github.com/zxc-rv/XKeen-UI/tree/b8ed60c098594c356c0ae871f77fc6598e0a9c8c). В обоих APK сохранены оригинальный текст MIT и `Copyright (c) 2026 zxc-rv`.

## Что умеет

- **Вся LAN через Mihomo по правилам профиля.** Трафик устройств домашней сети перехватывается и уходит в прокси только по правилам вашего YAML или подписки; остальное идёт напрямую.
- **Не мешает другим программам на роутере.** Перед запуском проверяется совместимость со сторонними правилами nftables; при конфликте запуск отклоняется с понятной причиной.
- **Управление — из домашней сети.** Запуск, перезапуск и «Применить» на работающем шлюзе — с устройства в основной LAN. Через Tailscale панель открывается для просмотра и остановки.

## Что нового

- **«Применить» на работающем шлюзе снова работает.** В 0.1-r26 замена профиля на запущенном шлюзе отказывала с `PROFILE_REQUIRED`; теперь новый профиль подменяет работающий без остановки.
- **Сборка без личных следов.** В бинарниках и установщике нет путей сборочной машины и имени её пользователя.
- **Новая нумерация.** Версия пакетов `0.1.26.2`: apk-tools 3 не принимает `0.1-r26.2`.

## Обновление

[Быстрый старт одной командой по SSH](https://github.com/First026/XkeenWRT-Mihomo#быстрый-старт) — чистая установка или обновление с 0.1-r26. Перед обновлением нажмите в панели **Остановить**.

Пакеты 0.1-r26 и более ранних выпусков больше не публикуются, поэтому откат на них не поддерживается.
