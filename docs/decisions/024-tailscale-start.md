# 024. Запуск шлюза через Tailscale — отменено

**Статус: отменено владельцем 18 ноября 2026.** Решение предлагало разрешить ▶ «Запустить», «Перезапустить» и «Применить» на работающем шлюзе с Tailscale-входа и подтверждать такое поколение пробами самого роутера: DNS шлюза и выход через прокси. Его реализовал выпуск 0.1.26.1. Владелец её отменил: Tailscale-доступ был нужен для проверки на роутере 2, а не как способ управления шлюзом. Выпуск 0.1.26.1 снят с публикации, функция удалена в 0.1.26.2.

Действует прежняя граница [решения 021](021-independent-inputs-and-revalidation.md). Через Tailscale можно открыть панель, смотреть состояние, остановить шлюз и выключить перехват. Включение шлюза, перезапуск входов и замена профиля на работающем шлюзе — только с клиента основной IPv4 LAN. В журнале и манифестах нет поля канала управления, поэтому их формат совпадает с r26.
