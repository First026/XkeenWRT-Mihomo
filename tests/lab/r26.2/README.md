# Стенд приёмки 0.1.26.2 (С1–С4)

Одноразовая VM OpenWrt 25.12.6 `armsr/armv8` под QEMU TCG; хост — сборочная VM, рабочие роутеры не используются. Основа — стенд [r26](../r26-native/README.md): те же образы, `init`, `boot.sh`, `console.py`.

Добавлено к r26:
- **Tailscale-вход.** `tailscale0` — veth; в netns `xk-ts` стоит администратор в tailnet 100.64.20.2, роутер — 100.64.10.1 (адреса синтетические, из 100.64.0.0/10). Сеть `tailscale` (proto none, device `tailscale0`) в зоне `lan`. Нужен, чтобы проверить: через Tailscale запуск и перезапуск запрещены, остановка разрешена.
- **Лабораторный «интернет».** На WAN-пире: DNS отдаёт `www.gstatic.com` → 1.2.3.4 (адрес «публичный»: защита dnsmasq от rebinding отбрасывает частные и тестовые сети); там HTTPS (второй Mihomo с лабораторным CA, CA добавлен в бандл гостя) и Shadowsocks на 10.0.0.3:8388. Прямой трафик LAN к 1.2.3.4 пир отбрасывает, поэтому этот сайт открывается у LAN-клиента только через прокси. Второй сайт, 1.2.3.5:80, доступен напрямую.
- **Профиль с правилами:** `DOMAIN-SUFFIX,gstatic.com,lab-ss` и `MATCH,DIRECT`.

Порядок:
1. `./prepare.sh <копия пары r26> <каталог с 0.1.26.2> <mihomo-linux-arm64-v1.19.34.gz>` — образы GHCR, подписанные индексы и пакеты OpenWrt, пара r26 (больше не публикуется, нужна своя копия), пара 0.1.26.2 и `.run`, лабораторный CA.
2. `XK_LAB=… ../r26-native/boot.sh &`, затем через `console.py`: `setup.sh`, `c1.sh` (на чистом диске: r26 → 0.1.26.2 установщиком), `c2.sh`, `c3.sh`, `c4.sh`.

| Сценарий | Что проверяет |
|---|---|
| С1 | Обновление r26 → 0.1.26.2 установщиком `.run`: профиль, Mihomo и owner сохраняются; ▶ из LAN работает |
| С2 | Вся LAN через шлюз по правилам: сайт из правила — через прокси, остальное — напрямую; без прокси пропадает только первый |
| С3 | Из LAN: «Применить» на работающем шлюзе заменяет поколение, затем «Перезапустить» и Stop |
| С4 | Через Tailscale: панель открывается, ▶ (`NETWORK_MANAGEMENT`) и перезапуск (`UNSUPPORTED`) отклонены, Stop работает |

Правка файла в работающем госте: `./put.py $XK_LAB/serial.sock ЛОКАЛЬНЫЙ_ФАЙЛ ПУТЬ_В_ГОСТЕ` — без base64 (его нет в busybox гостя), файл подменяется только при совпадении SHA-256.

Отклонения от устройства: `armsr/armv8`, veth вместо портов, Wi‑Fi и настоящего Tailscale, лабораторный CA и «интернет».
